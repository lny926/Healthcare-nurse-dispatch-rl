# Reinforcement Learning for Nurse Dispatching in Healthcare Simulation

A Master's research project investigating reinforcement-learning-based
nurse dispatching under dynamic healthcare workloads.

The project compares a PPO-based dispatching policy with rule-based
scheduling strategies including FCFS and shortest-distance dispatching.

## Key Features

- Healthcare nurse dispatch simulation
- PPO reinforcement learning policy
- FCFS and shortest-distance baselines
- Repeatable experiments with configurable random seeds
- Operational evaluation metrics
- Streamlit experiment interface
- Unity WebGL visualisation

## Tech Stack

Python · PyTorch · PPO · Pandas · Streamlit · Unity
